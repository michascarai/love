# Animação Love

Uma animação em Python que desenha um coração preto de fundo com a palavra `love` surgindo e desaparecendo em ondas.

## Como executar

É necessário ter Python instalado. No Windows, abra um terminal nesta pasta e execute:

```powershell
python love.py
```

A animação usa as bibliotecas padrão `turtle` e `math`, incluídas no Python.
